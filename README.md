# FormGen 📝⚡

FormGen is an AI-powered web application that automatically generates fully structured Google Forms based on simple text prompts. It connects directly with Google OAuth 2.0 to create, store, and manage forms seamlessly inside your Google account.

👉 **[Try FormGen Live on Render](https://formgen-9pjf.onrender.com)**

---

## ✨ Features
* **AI-Powered Form Generation:** Instantly generate questions, options, and response structures using Groq AI.
* **Direct Google Forms Integration:** Automatically builds and saves forms to your Google Drive via the Google Forms API.
* **Google OAuth 2.0 Authentication:** Secure user authentication with token persistence and scope access.
* **Dashboard & Workspace Management:** View, organize, and track active forms in real-time.
* **Supabase Integration:** User profiles and workspace metadata stored securely.

---

## 🛠️ Tech Stack
* **Backend:** Python, Flask, Gunicorn
* **AI Engine:** Groq LLM API
* **Database:** Supabase
* **Google APIs:** Google Forms API, Google Drive API, Google OAuth 2.0
* **Frontend:** HTML5, CSS3, JavaScript
* **Deployment:** Render
